# Product Design guide, ready for Loom

This folder holds the Product Design Prompt Kit as 29 Markdown notes, laid out as it should appear in Loom:

```
Guides & Tutorials/
  Product Design/
    Product Design Prompt Kit.md      start page, links to everything
    01 How designers think.md  ...  11 Resource library.md
    Resources/
      Design resources - <topic>.md   17 notes, 428 links in total
```

`Product-Design-for-Loom.zip` is the same folder, zipped.

## What the notes use

- Obsidian-style wikilinks between notes, resolved by note name. Renaming a note breaks its links.
- Standard Markdown tables, fenced code blocks for the copyable prompts, and one task list in `09 Review checklist.md`.
- No front matter, images, attachments or embeds.

## Where it came from

The notes are generated from `guides/product-design-prompt-kit.html` in this repository. The interactive version is at https://claude.ai/artifact/7yyTa28XMqQKprrMPxFtRA. External links were last checked on 18 November 2026.
