# Review checklist

Part of [[Product Design Prompt Kit]].

A designer's value is as much in judging as in making. Run each design the AI returns through these questions. Any "no" becomes your next feedback prompt, using [[07 Feedback phrases]].

- [ ] **One clear primary action**: Is there exactly one thing that looks most clickable?
- [ ] **Hierarchy reads right**: Squint at it. Does the eye land on the most important thing first?
- [ ] **You know where you are**: Can the user tell which screen this is and how to go back?
- [ ] **All states designed**: Empty, loading, error, success and offline, not only the ideal screen.
- [ ] **Edge cases hold**: Very long text, zero items, one item, a thousand items.
- [ ] **Consistent spacing**: Do gaps come from one scale, or are they arbitrary?
- [ ] **Restrained type**: Two typefaces or fewer, and about five sizes at most.
- [ ] **Targets big enough**: 44 pt on iOS, 48 dp on Android, and not crammed together.
- [ ] **Contrast passes**: 4.5:1 for body text, 3:1 for large text and controls.
- [ ] **User's words**: Labels say what users recognise, not internal or technical names.
- [ ] **Safe destructive actions**: Deleting is undoable or clearly confirmed.
- [ ] **Platform conventions**: Back gesture, navigation and controls behave as users expect.
- [ ] **Keyboard works (web)**: Everything can be reached and used without a mouse.
- [ ] **Fewest steps**: Could the happy path lose a tap or a field?
- [ ] **Solves the brief**: Does it actually serve the job-to-be-done you started with?
