# Product Design Prompt Kit

Experienced product designers don't ask for "a nice screen". They name the user, the job, the platform, the states and the stage of work, then judge the result against known principles. This kit gives you that vocabulary, the order to work in, and prompts you can copy.

The running example is Quick Capture for Loom: jot a note in seconds, with no filing decision. Swap in your own feature wherever you see square brackets.

## How to use it

1. Read [[01 How designers think]] and [[02 Artefacts by stage]] once.
2. Pick the artefact you need and copy its prompt from [[05 Prompt templates]].
3. Fill the brackets, adding lines from [[04 Prompt building blocks]].
4. Judge the result with [[09 Review checklist]].
5. Steer the next attempt with [[07 Feedback phrases]].
