# Design resources - AI tools and prompting

Part of [[11 Resource library]] in the [[Product Design Prompt Kit]].

Where to run your prompts, and how to write them well.

19 links. A star marks an essential. Last link check: 18 November 2026.

- **[Prompt engineering overview](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview)** ★ (Anthropic; guideline; free). The official guide to prompting Claude: be clear and direct, give examples, assign a role, let it think. *In a prompt:* "Before answering, think through the user's goal and the constraints step by step."
- **[Mermaid Live Editor](https://mermaid.live/)** ★ (Mermaid; tool; free). Paste the Mermaid flowchart that the user flow template produces and see it drawn instantly. *In a prompt:* "Output the flow as a Mermaid flowchart I can paste into mermaid.live."
- **[Claude](https://claude.ai/)** (Anthropic; tool; free tier). Generates working prototypes, wireframes and design documents as artifacts you can open and iterate on. *In a prompt:* "Build this as a single HTML artifact I can click through."
- **[Figma Make](https://www.figma.com/make/)** (Figma; tool; free tier). Prompt-to-prototype inside Figma, able to start from your existing designs and libraries. *In a prompt:* "Use my attached Figma frame as the starting point; keep its styles."
- **[v0](https://v0.app/)** (Vercel; tool; free tier). Generates React interfaces with shadcn/ui and Tailwind from a prompt or screenshot. *In a prompt:* "Generate this screen with shadcn/ui components and show all states."
- **[Lovable](https://lovable.dev/)** (Lovable; tool; free tier). Builds full web apps from prompts, with a visual editor for point-and-click changes. *In a prompt:* "Build the capture flow end to end with mock data, no backend."
- **[Bolt](https://bolt.new/)** (StackBlitz; tool; free tier). Prompt-to-app in the browser, good for quick throwaway prototypes. *In a prompt:* "Scaffold a clickable prototype of these four screens."
- **[Stitch](https://stitch.google.com/)** (Google; tool; free). Generates mobile and web UI designs from prompts and exports to Figma or code. *In a prompt:* "Generate three layout variations of this screen for comparison."
- **[Prompt engineering guide](https://developers.openai.com/api/docs/guides/prompt-engineering)** (OpenAI; guideline; free). OpenAI's prompting guidance. The principles carry across tools. *In a prompt:* "Give the model the context, the format, and an example of good output."
- **[Figma](https://www.figma.com/)** (Figma; tool; free tier). The industry-standard design tool. Even if AI drafts the screens, this is where teams refine and hand off. *In a prompt:* "Structure the output so it maps to Figma frames, components and variants."
- **[Figma Resource Library](https://www.figma.com/resource-library/)** (Figma; reference; free). Short explainers on almost every design topic, with templates. *In a prompt:* "Explain wireframing the way Figma's resource library does, then apply it."
- **[Excalidraw](https://excalidraw.com/)** (Excalidraw; tool; free). Hand-drawn style whiteboard for quick flows and low-fidelity sketches. The roughness signals 'not final'. *In a prompt:* "Describe the wireframe as boxes I can sketch in Excalidraw."
- **[tldraw](https://www.tldraw.com/)** (tldraw; tool; free). A fast infinite canvas for sketching flows and wireframes. *In a prompt:* "Lay out the flow as a left-to-right diagram of screens and arrows."
- **[Whimsical](https://whimsical.com/)** (Whimsical; tool; free tier). Flowcharts, wireframes and mind maps with tidy defaults. *In a prompt:* "Give me the flow as a list of nodes and connections I can redraw."
- **[Balsamiq Wireframing Academy](https://balsamiq.com/learn/)** (Balsamiq; course; free). Free lessons on wireframing and UI design fundamentals, with a control-by-control guide. *In a prompt:* "Wireframe at Balsamiq fidelity: boxes, labels and real text only."
- **[Penpot](https://penpot.app/)** (Penpot; tool; free). An open-source design tool built on web standards, so designs map closely to CSS. *In a prompt:* "Express layout as flex and grid so it maps directly to code."
- **[Framer](https://www.framer.com/)** (Framer; tool; free tier). Design and publish real websites with strong interaction and animation tools. *In a prompt:* "Design the marketing page as sections I can rebuild in Framer."
- **[CARE: Structure for Crafting AI Prompts](https://www.nngroup.com/articles/careful-prompts/)** ★ (NN/g; article; free). A four-part prompt structure written for UX work: context, ask, rules, examples. A simpler cousin of the anatomy in this kit. *In a prompt:* "Structure the prompt as context, ask, rules and examples."
- **[Guide to the Figma MCP server](https://help.figma.com/hc/en-us/articles/32132100833559-Guide-to-the-Figma-MCP-server)** (Figma; guideline; free). How AI coding tools can read your Figma designs directly, so generated code matches them. *In a prompt:* "Read the selected Figma frame and build it using our existing components."
